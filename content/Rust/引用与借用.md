## 什么是引用

**引用**（Reference）可以让代码使用一个值，而不拿走它的所有权。这种通过引用访问数据的方式，就是借用。

```rust
let s1 = String::from("hello");
let s2 = &s1; // s2 是 s1 的引用,s1 仍然拥有该 String

println!("{s1}"); // 正常:s1 仍然有效
println!("{s2}"); // 正常:s2 借用了 s1
```


> [!info] 引用 vs 所有权
> 
> |          | 所有权(Owner)          | 引用(&T)                  |
> | -------- | ---------------------- | ------------------------- |
> | 修改值   | 可以(如果是 mut)       | 默认不可变                |
> | 释放内存 | 离开作用域时调用 drop  | 不负责释放                |
> | 数量限制 | 同一时刻只有一个所有者 | 可同时存在多个不可变引用  |
> | 消耗方式 | Move / Drop            | Copy(引用自身实现了 Copy) |
> 


## 引用的基本语法

### 不可变引用 `&T`

```rust
let x = 42;
let r = &x;       // r 的类型是 &i32,读作"对 i32 的引用"

println!("x = {x}, r = {}", *r); // *r 解引用,获取原始值
```

### 可变引用 `&mut T`

```rust
let mut x = 42;
let r = &mut x;   // r 的类型是 &mut i32
*r += 1;          // 通过可变引用修改原值

println!("x = {x}"); // 43
```


> [!important] 可变引用的前提
> 要创建可变引用，原始变量**必须声明为 `mut`**。不可变变量不能产生可变引用。


## 借用规则

借用时主要要注意下面两条规则，编译器会检查这些借用有没有重叠：

### 规则一:多个不可变引用可以共存

```rust
let s = String::from("hello");

let r1 = &s;
let r2 = &s;
let r3 = &s; // 任意多个不可变引用,完全合法

println!("{r1} {r2} {r3}");
```

### 规则二:不可变引用与可变引用不能同时存在


> [!warning] 以下两段代码故意无法编译
> 这两段代码都在后面继续使用了前面的引用，所以借用会发生重叠。E0499 表示可变借用重叠，E0502 表示共享借用和可变借用冲突。
> 
> ```rust
> let mut s = String::from("hello");
> 
> let r1 = &mut s;
> let r2 = &mut s;   // E0499:第二次可变借用
> r1.push('!');       // r1 在后面仍被使用,两个借用发生重叠
> r2.push('?');
> ```
> 
> ```rust
> let mut s = String::from("hello");
> 
> let r1 = &s;
> let r2 = &mut s;   // E0502:共享借用仍有效时进行可变借用
> println!("{r1}");  // r1 的最后一次使用在可变借用之后
> r2.push('!');
> ```


正确做法是让前一个借用的最后一次使用先发生，或用代码块明确缩短借用范围：

```rust
let mut s = String::from("hello");

{
    let r1 = &mut s;
    r1.push('!');
} // r1 的借用在这里结束

let r2 = &mut s;
r2.push('?');

let shared = &s;
println!("{shared}"); // 共享借用的最后一次使用
let unique = &mut s;
unique.push('.');
```


> [!warning] 为什么要有这些限制
> 没有同步地同时读写同一块内存，就可能产生**数据竞争**（Data Race）。可以从下面几个条件理解：
> 
> 1. 两个或多个指针同时访问同一数据
> 2. 至少有一个指针在写入
> 3. 没有同步机制
> 
> 安全 Rust 的借用规则会限制这种无同步的重叠访问。


### 借用规则的形式化表述

在任意给定时间，以下**二者只能选其一**：

- 任意多个不可变引用
- **恰好一个**可变引用

此外，所有引用**必须始终是有效的**（不能悬垂）。

## 引用的作用域

借用检查器从引用创建处分析到它的**最后一次使用**。借用可以在词法代码块结束前停止约束后续代码，但引用变量自身的词法作用域仍由代码块决定：

```rust
let mut s = String::from("hello");

let r1 = &s;       // r1 的借用开始
let r2 = &s;       // r2 的借用开始
println!("{r1} {r2}"); // r1, r2 最后一次使用

// r1 和 r2 的借用在此结束,变量的词法作用域仍在当前代码块内

let r3 = &mut s;   // 合法:之前的不可变借用已经结束
r3.push_str(", world!");
println!("{r3}");
// r3 的借用最晚在最后一次使用后结束
```

### 非词法生命周期(NLL)

早期借用检查较多地按照词法代码块推断借用有效期，上面的代码可能被拒绝.NLL（稳定用于 Rust 2018 edition）会根据控制流和最后一次使用推断借用何时不再约束后续代码，减少了很多不必要的编译错误。它没有改变变量由代码块决定的词法作用域。

```rust
let mut s = String::from("hello");

let r1 = &s;
let r2 = &s;
// 如果这里是作用域边界(旧规则),以下代码会失败
// 但 NLL 允许,因为 r1, r2 在此之后不再使用

let r3 = &mut s; // NLL 下编译通过
```


> [!info] NLL 的实际意义
> NLL 会根据引用实际使用到哪里来检查借用，不再只看代码块的边界。所以有些看起来“前面的引用还在”，但后面已经不再使用它的代码，也能通过编译。


## 引用与函数

### 引用作为函数参数

```rust
fn calculate_length(s: &str) -> usize {
    s.len()
}

fn append_world(s: &mut String) {
    s.push_str(", world!");
}

fn main() {
    let mut s = String::from("hello");

    let len = calculate_length(&s); // 不可变借用
    println!("length: {len}");      // s 仍然可用

    append_world(&mut s);           // 可变借用
    println!("{s}");                // "hello, world!"
}
```


> [!info] 函数签名即契约
> 从参数类型可以先看出函数拿到了哪种访问权限：
> 
> - `&T` ：函数只会读取数据
> - `&mut T`：函数可能会修改数据
> - `T` ：函数会获取所有权，调用方之后不能再使用该值


### 引用作为返回值

函数返回引用时，需要让编译器知道它和哪个输入引用有关。无法按省略规则推断时，就要标注**生命周期**（Lifetime）：

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}
```

生命周期注解 `'a` 表示返回的引用与参数 `x` 和 `y` 的生命周期相关联。


> [!important] 生命周期是借用检查的核心
> 生命周期（lifetime）可以先粗略理解成“引用有效的范围”，后面再看专门的笔记。


## 悬垂引用(Dangling Reference)

悬垂引用是指向已释放内存的引用.Rust 编译器保证它**永远不会发生**：

```rust
fn dangle() -> &String {     // 预期返回 String 的引用
    let s = String::from("hello");
    &s                        // 返回引用...
}                             // ...但 s 在这里被释放!
// 编译错误:`s` does not live long enough
```

正确的做法是返回数据本身（转移所有权）：

```rust
fn no_dangle() -> String {
    let s = String::from("hello");
    s // 所有权移出,调用方负责释放
}
```

## 切片:一种特殊的引用

### 字符串切片 `&str`

```rust
let s = String::from("hello world");

let hello: &str = &s[0..5];   // "hello"
let world: &str = &s[6..11];  // "world"
let all: &str = &s[..];       // "hello world"
```

切片的本质是：一个**指针** + 一个**长度**，不拥有底层数据。

```text
&str 内存布局(栈):
+--------+--------+
| 指针    | 长度    |
| (usize) | (usize) |
+--------+--------+
   |        5
   v
+---+---+---+---+---+
| h | e | l | l | o |
+---+---+---+---+---+
   堆(或数据段)
```

### 数组切片 `&[T]`

```rust
let a = [1, 2, 3, 4, 5];
let slice: &[i32] = &a[1..3]; // 引用 a 的一部分,而非复制
assert_eq!(slice, &[2, 3]);
```


> [!info] 切片是胖指针
> 切片`&[T]`和`&str`由两部分组成：
> 
> 1. **指针**：指向数据起始地址
> 2. **长度**：元素个数
> 
> 因此切片引用通常占两个机器字，而指向定长类型的普通引用 `&T` 通常占一个机器字；具体字节数随目标平台而变化。


### 切片作为函数参数

```rust
// 权威实现的签名:
// fn first_word(s: &str) -> Option<&str>

fn main() {
    let s = String::from("hello world");
    match first_word(&s) { // &String 可自动转为 &str
        Some(word) => println!("{word}"),
        None => println!("输入为空"),
    }

    assert_eq!(first_word(""), None);
    assert_eq!(first_word("hello"), Some("hello"));
}
```

这个函数只把 ASCII 空格当成分隔符，完整代码见[切片笔记中的实现](Rust/切片.md)。


> [!important] 优先用 &str 而非 &String
> `&str` 可以接受 `&String` 和 `&str` 两种参数（通过 Deref 强制转换），
> 而 `&String` 只能接受 `&String`。编写 API 时优先使用 `&str`。


## 常见借用错误

### 错误一:同时持有不可变和可变引用

```rust
let mut v = vec![1, 2, 3];

let first = &v[0];  // 不可变借用
v.push(4);          // 错误:不能在有不可变借用时修改
println!("{first}");
```

### 错误二:在循环中修改集合

```rust
let mut v = vec![1, 2, 3];

for item in &v {     // 不可变借用 v
    v.push(*item);   // 错误:不能在迭代期间修改 v
}
```

### 错误三:返回局部变量的引用

```rust
fn return_ref() -> &i32 {
    let x = 42;
    &x // 错误:x 在函数返回后被释放
}
```


> [!info] 借用错误会提前暴露
> 上面这些错误都会在编译时被发现。刚开始可能会觉得限制很多，但这样就不用等程序跑起来，才发现引用的数据已经失效了。



> [!important] 这部分的重点
> 引用允许在不转移所有权的情况下访问数据，编译器会检查这些访问是否符合借用规则。
> 这里先分清 `&T` 和 `&mut T`，再结合切片和生命周期，理解引用到底能用到哪里。
