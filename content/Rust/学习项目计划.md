这些项目大致按难度往后排，每个项目集中练几个概念。这里记的是计划，不代表已经全部做完，做过的部分会单独说明。

## 第一阶段：熟悉基础语法

### 1. 猜数字游戏

- **练习重点**：变量、输入输出、`match`/`cmp`、循环
- 来自《Rust程序设计语言》第一章的经典例子

### 2. 命令行计算器

- **练习重点**：字符串解析、枚举(`enum`)、错误处理(`Result`)
- 支持加减乘除和括号表达式

### 3. Todo 命令行工具

- **练习重点**：`Vec`、结构体、文件读写（序列化/反序列化）
- 支持添加/删除/列出任务，数据持久化到 JSON 文件

## 第二阶段：深入核心概念

### 4. 文件搜索工具 (mini grep)

- **练习重点**：命令行参数(`clap` crate)、迭代器、泛型、trait
- 按关键字在文件中搜索并高亮匹配行
- 《Rust程序设计语言》第12章有完整实现

已经做出的标准库版本见[命令行文件搜索实践:minigrep](Rust/命令行文件搜索实践.md)。目前还没有用 clap，也没有做匹配高亮，主要练习了参数迭代器、借用原文的搜索、环境开关、原文件行号、自定义错误和 CLI 集成测试。后面准备继续尝试可测试输出和流式读取。

### 5. HTTP 请求工具 (mini curl)

- **练习重点**：网络编程、异步(`async`/`await`)、`tokio` 运行时
- 用 `reqwest` 发请求，支持 GET/POST，格式化输出响应

### 6. Markdown 转 HTML 转换器

- **练习重点**：字符串处理、模式匹配、第三方 crate 使用
- 解析 Markdown 语法输出 HTML

## 第三阶段：综合运用

### 7. 简单的 HTTP 服务器

- **练习重点**：`TcpListener`、多线程、`Arc`/`Mutex`
- 手动实现 HTTP 协议解析，返回静态文件

### 8. Redis 简易克隆 (命令存储)

- **练习重点**：`HashMap`、序列化、TCP 通信
- 支持 SET/GET/DEL 命令，键值对存储

### 9. 终端 UI 应用 (ratatui crate)

- **练习重点**：事件循环、状态管理、第三方库集成
- 做一个系统监控面板或文件管理器

## 第四阶段：有挑战性但很有趣

### 10. 小型数据库引擎

- **练习重点**：二进制格式、B-Tree、文件 I/O
- 参考《Let's Build a Simple Database》教程

### 11. WebAssembly 游戏

- **练习重点**：`wasm-bindgen`、前端交互
- 用 Rust 写逻辑，编译到浏览器运行

## 推荐学习路径

1. 先读 [《The Rust Book》中文版](https://kaisery.github.io/trpl-zh-cn/)
2. 每个阶段挑 1-2 个项目做，遇到问题查标准库文档
3. 创建、构建和验证项目时，配合使用 `cargo new` / `cargo build` / `cargo test`
4. 多看 [crates.io](https://crates.io) 上的优秀开源项目源码


> [!info] 后续安排
> 可以先从“猜数字”开始，再通过“mini grep”多练一下所有权和生命周期。后面的项目就按兴趣选，不必为了完成清单强行全部做一遍。
